# 오늘의 범위와 다음 단계

> 2026-11-16 최초 목업 계획입니다. 2026-11-17 디자인 반영·실제 백엔드 연동 기록은 [INTEGRATION.md](INTEGRATION.md)에 정리했습니다.

## 합의한 방향

- 충남 지역 목적지를 차로 방문하는 사용자.
- 프론트 담당 1명, 디자이너·백엔드 담당은 별도.
- 프론트 스택: React + TypeScript + Vite.
- 오늘 목표: 실제 구현의 틀을 확인할 최소 클릭형 모바일 웹 목업과 API 초안.
- 모바일 환경을 최우선으로 구현·검증하고 데스크톱은 같은 흐름을 확장한다.
- 서비스명·비주얼은 임시안이며 디자이너의 최종 시안을 반영할 예정.

## 모바일 우선 기준

- 주요 검토 폭은 360·390·430px이며, 작은 화면에서 먼저 화면과 동작을 확정한다.
- 검색·주차장 선택·내비 출발을 한 손으로 조작할 수 있게 구성한다.
- 주요 터치 영역은 최소 44×44px를 목표로 한다.
- 하단 고정 버튼은 기기 safe area와 본문 마지막 내용을 가리지 않아야 한다.
- 검색 키보드 표시, 긴 매장명, 긴 주차 안내, 모달 스크롤을 확인한다.
- 데스크톱 브라우저의 모바일 미리보기 외에 iOS Safari·Android Chrome에서 실제 동작을 검증한다.
- 외부 내비 실행·미설치 대체 동작은 실기기 검증을 완료한 뒤 연동 완료로 판단한다.

## 화면 흐름

1. `/`: 목적지 검색, 세 가지 예시 매장 바로가기.
2. `/search?q=...`: 이름·주소·주차 가능 여부를 보고 목적지 선택.
3. `/places/:placeId`: 주차 요약 → 주차장 선택 → 입구 → 비용·시간 → 도보 동선 → 등록·정산.
4. 내비 선택 모달: 기본 앱 저장 → 데모 길안내 확인.

주차 가능이면 연결된 주차장과 대체 주차장을 표시한다.
주차 불가이면 주변 주차장으로 이어진다.
정보 없음은 주차 불가로 취급하지 않으며, 대체 주차장도 없으면 출발 버튼을 제공하지 않는다.

## 오늘의 완료 기준

- 목 데이터로 검색부터 내비 선택까지 클릭할 수 있다.
- 주차장 선택 시 입구·요금·동선·정산 안내가 함께 바뀐다.
- 세 가지 주차 상태와 로딩·빈 결과·실패 상태가 분리된다.
- 디자이너가 화면 구조를 검토할 수 있다.
- 백엔드가 API 타입과 응답 예시를 검토할 수 있다.
- TypeScript 검사와 프로덕션 빌드가 통과한다.

## 백엔드와 먼저 정할 것

1. 장소 검색 원천: 외부 장소 검색, 자체 등록 데이터, 두 방식의 결합 중 선택. 외부 장소 ID와 내부 장소 ID의 매핑.
2. 충남 데이터 확보 범위: 입구 좌표·사진·요금·운영시간·매장별 무료 조건의 출처와 검증.
3. 주차 가능 여부의 의미: `available`은 주차 시설 이용 가능이며 실시간 잔여면을 뜻하지 않음.
4. 도보 시간·동선: 수동 등록 안내인지 실제 경로 탐색 결과인지. 정보가 없으면 null/빈 배열로 반환.
5. 운영시간 경고: 오늘 목업은 저장된 경고. 실제 방문 예정 시간 기반 경고는 서버/프론트 책임과 시간대·자정·휴무 처리 합의 필요.
6. 거리·운영 여부를 고려한 대체 주차장 추천과 정렬 기준. 현재 화면은 도보 시간 오름차순, 미확인은 마지막.
7. API 기준 주소·CORS·에러 포맷·일정·담당자 합의.

## 디자이너에게 필요한 상태

검색 기본 / 입력 / 로딩 / 결과 / 빈 결과 / 오류.
상세 주차 가능 / 불가 / 미확인 / 주차장 선택 / 입구 사진 없음 / 운영시간 경고 / 도보 정보 없음.
내비 선택 / 기본 앱 기억 / 미리보기 확인.
모바일 하단 버튼과 키보드·긴 이름·긴 안내 문구를 고려한다.

## 실제 연동 단계

1. API 계약 확정 후 HTTP 어댑터로 전환하고 실제 데이터 확인.
2. 공식 내비 문서에 따라 Naver/Kakao/TMAP 링크와 앱 미설치 대체 동작 구현.
3. 실제 입구 좌표로 iOS·Android 실기기에서 목적지, 앱 실행, 복귀 검증.
4. 디자인 반영과 네트워크 오류·API 응답 검증 보강.

원탭 정확도 피드백은 원래 MVP 요구사항에 있으므로 실제 MVP 단계에서 추가한다.
로그인·즐겨찾기·만료 알림·점주 기능·실시간 잔여면·지도 SDK는 오늘 목업 범위 밖이다.
