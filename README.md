# 입구 — 충남 주차 안내 프론트엔드 목업

목적지 검색 → 주차 정보 확인 → 주차장 선택 → 내비 앱 선택 → 길안내 미리보기.

React + TypeScript + Vite / React Router / CSS Modules. 로그인, 위치 권한, API 키 없이 실행됩니다.
`입구`는 목업용 임시 서비스명입니다. 디자인과 명칭은 디자이너 협업 시 변경하면 됩니다.

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

터미널에 출력되는 Local URL로 접속하세요.

```sh
npm run build
npm run preview
```

`build`는 TypeScript 검사 후 정적 결과물을 `dist/`에 생성합니다.
호스팅 시 `/places/*`, `/search` 등 직접 접근도 `index.html`로 전달하는 SPA fallback이 필요합니다.

## 목업 범위

- 매장명·지역·업종 검색, 검색 결과, 목적지 주차 상세
- 주차 가능 / 주차 불가 / 정보 없음 구분
- 매장 주차장과 주변 주차장 선택
- 입구 예시 이미지, 요금·운영시간, 운영시간 불일치 안내
- 도보 단계, 무료 주차 등록·정산 방법, 데이터 확인 시점
- 내비 앱 선택과 기본 앱의 기기 내 저장
- 로딩, 빈 결과, 없는 목적지·페이지, API 실패 시 재시도
- 모바일 하단 출발 버튼, 키보드 접근, 내비 선택 모달

모든 매장·주차장·좌표·요금은 **가상의 테스트 데이터**입니다.
입구 이미지는 실제 사진 대신 예시 일러스트입니다.
내비 선택은 미리보기이며 외부 앱을 실행하지 않습니다.
도보 안내는 예시 문구이고 지도 SDK나 경로 탐색 API를 연결하지 않았습니다.
운영시간 경고는 서버 응답 문구를 표시하며 현재 시간·방문 예정 시간으로 자동 계산하지 않습니다.

## 테스트 시나리오

1. 홈에서 `천안` 검색 → `모퉁이 커피` → 건물 주차·무료 조건·21시 마감 경고 확인.
2. 같은 상세에서 `가온 공영주차장` 선택 → 해당 요금·도보 동선으로 변경되고 매장 할인·마감 경고가 제거되는지 확인.
3. `내비로 출발` → 앱 선택 → `길안내 미리보기` → 미리보기 안내 확인. 다시 열거나 새로고침 후 저장한 앱 확인.
4. `아산` 검색 → `온양 작은책방` → 주차 불가와 대체 주차장 도보 3분 확인.
5. `공주` 검색 → `공주 느린식탁` → 정보 없음, 대체 주차장 없음, 출발 버튼 없음 확인.
6. `없는매장` 검색 → 빈 결과. `/places/not-found`와 잘못된 URL 직접 접근 → 복구 링크 확인.
7. 390px 모바일 폭에서 위 흐름 반복, 가로 넘침·하단 버튼 가림 여부 확인.

## 실제 API로 전환

`.env.example`을 `.env.local`로 복사한 후 백엔드 주소를 설정하고 개발 서버를 다시 실행하세요.

```dotenv
VITE_API_BASE_URL=https://your-api.example.com
```

값이 없으면 목 데이터, 값이 있으면 HTTP API를 사용합니다. 공개 환경변수에 비밀키를 넣지 마세요.
응답 형태는 [API 초안](docs/API.md)과 `src/domain/parking.ts`를 따릅니다.
HTTP 어댑터는 JSON 응답을 신뢰하는 초기 구현이며 런타임 스키마 검증은 추후 필요에 따라 추가합니다.
백엔드에서 프론트 주소의 CORS를 허용해야 합니다. 인증은 아직 구현하지 않았습니다.

서체는 Google Fonts의 Noto Sans KR을 요청하고, 연결할 수 없으면 시스템 서체를 사용합니다.
